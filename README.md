* *The direct codebase implementation companion to my technical architectural publication: "[The Green Avalanche: AI Can Generate Code Faster Than Humans Can Verify It.](https://medium.com/@prachi.panditrao/the-green-avalanche-ai-can-generate-code-faster-than-humans-can-verify-it-0f6becef39c6)"*

### 🤖 [Dynamic Swagger MCP Agent](https://github.com/prachipanditrao/dynamic_swagger_mcp_agent)
An autonomous Model Context Protocol server built with **Java and Spring AI** designed to dynamically intercept, map, and programmatically validate complex live OpenAPI configurations for LLM tool calling execution graphs.
